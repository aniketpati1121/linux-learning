# 💻 Basic Linux Commands

## Navigation Commands

```
pwd        # show current directory
ls         # list files
ls -l      # detailed list
cd dir     # change directory
cd ..      # go back
cd ~       # go to home
```

## File & directory management 

```
touch file.txt     # create file
mkdir folder       # create directory
rm file.txt        # delete file
rm -r folder       # delete directory
cp src dest        # copy file
mv src dest        # move/rename file
```

## Viewing file content 

```
cat file.txt       # show content
less file.txt      # view page by page
head file.txt      # first 10 lines
tail file.txt      # last 10 lines
```

## File permission 

```
chmod 755 file     # change permission
chown user file    # change owner
```

## System information 

```
whoami     # current user
id         # user + group info
uname -a   # system info
```

## Help Commands 

```
man ls     # manual page
ls --help  # quick help
```

## Shell Prompt related commands 
```
sudo -i  >> go to root user

su - (username ) ex : su - aniketpatil  >> go to direct user prompt

exit  >> direct go root user
```
