# 🐧 Linux Introduction

## 📌 What is Linux?

👉 Linux is an **open-source operating system** based on Unix.  
It manages hardware and software resources and allows users to interact with the system.

---

## 📌 Why Linux is Important?

- Used in **servers, cloud, DevOps, MLOps**
- High **security & stability**
- Open-source (free to use & modify)
- Supports automation and scripting
 
---

## 📌 Key Features of Linux

- Multi-user 👥  
- Multi-tasking ⚡  
- Secure 🔒  
- Open-source 💻  
- Portable 🌍  

---

## 📌 Linux Architecture (Basic)

1. **Kernel** → Core of OS (hardware control)  
2. **Shell** → Interface to interact (commands)  
3. **File System** → Organizes files & directories  

---

## 📌 Common Linux Distributions

- Ubuntu  
- CentOS  
- Red Hat Enterprise Linux (RHEL)  
- Debian  

--- 

# 🔐 sudo Command (Superuser Do)

## 📌 What is sudo?

👉 `sudo` allows a normal user to run commands with **admin (root) privileges**

📌 Marathi:  
👉 `sudo` वापरून normal user admin (root) permission ने command run करू शकतो  

---

## 📌 Basic Syntax

```bash
sudo command
```
