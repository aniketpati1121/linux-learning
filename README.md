# RHCSA Syllabus (Linux)

## 1. Linux Basics
- Linux overview
- Terminal & shell (bash)
- Access (local / SSH)

## 2. Basic Commands
- Navigation: pwd, cd, ls
- File ops: cp, mv, rm, touch
- View files: cat, less, head, tail
- Help: man

## 3. Text Processing
- grep, cut, awk, sed
- sort, uniq
- Redirection: >, >>
- Pipes: |

## 4. Permissions
- chmod, chown, chgrp
- r, w, x
- SUID, SGID, sticky bit

## 5. Users & Groups
- useradd, usermod, userdel
- passwd
- groupadd, groupdel

## 6. Process Management
- ps, top
- kill
- jobs, fg, bg
- nice, renice

## 7. Package Management
- yum / dnf
- install, update, remove
- repos

## 8. Services (systemd)
- systemctl start/stop/status
- enable/disable

## 9. Storage
- lsblk, fdisk
- mount, umount
- /etc/fstab
- LVM (pv, vg, lv)
- swap

## 10. Networking
- ip a
- hostnamectl
- nmcli
- ping, curl

## 11. Security
- firewalld, firewall-cmd
- SELinux (getenforce, setenforce)

## 12. Archiving
- tar
- gzip, bzip2, xz

## 13. Scheduling
- crontab
- at

## 14. Logs
- journalctl
- /var/log
- df, du, free

## 15. SSH
- ssh, scp
- ssh config
- key-based auth

## 16. Containers (Basic)
- podman basics

## 17. Troubleshooting
- boot issues
- network issues
- service issues
